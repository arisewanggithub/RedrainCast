Privacy

This policy describes RedrainCast for Windows and Android and this product website. Platform differences are explained below. It is a description of current behavior, not a security certification.

Local sharing requires trust

Screen content and selected audio go directly to the peer over the network. No account or cloud relay is used for casting. Discovery and casting are not authenticated or encrypted, and incoming casts are automatically accepted. A device that can reach the receiver's listening port may send content. Use a trusted LAN only; do not expose listening ports to the internet.

Information used during a cast

RedrainCast processes the screen/window content and optional audio you choose to send, and incoming media while receiving. Discovery and connections use device names, network addresses, ports and receiver availability. Session negotiation and diagnostics also use codec, device and playback information. Discovery makes device information visible to nearby network participants.

The apps do not intentionally save screen/audio payloads as recordings during normal casting or send them to a RedRain server. The receiving peer has access to the shared media; this policy cannot control what someone on that device does with it. Avoid sharing private content with anyone you do not trust.

Windows

  • You select a window or display and may enable output audio. This is not microphone capture.
  • Sharing settings are saved in the current user's local application data. Capture selections, connection targets and active sessions are not persisted.
  • A bounded diagnostic log remains in memory. It can contain device/network addresses, codec information and errors, but not media payloads. Normal casting does not write a media recording.
  • Receiving pauses while sending and resumes afterward. Closing the app normally stops its capture and listeners. Receiving video does not grant remote keyboard or mouse control.

Android

  • Screen sharing uses Android's MediaProjection consent. Optional audio can capture eligible app playback or the microphone, depending on your selected source. Audio capture requires Android's audio-recording permission. The app does not declare a camera permission.
  • Network/Wi-Fi permissions support discovery and connections. Where Android requires local-network permission, denial prevents LAN operations until permission is granted. Foreground-service and notification permissions support ongoing sharing; permission availability and prompts vary by Android version.
  • Sharing preferences, audio-mute restoration state and a limited set of recent sender diagnostic/session-failure information are stored in app-private preferences. Diagnostics may include session identifiers, timestamps and failure information. Android system logs may also contain connection, codec and error details; they are not the same as Windows' memory-only log.
  • Android checks public GitHub release metadata when a new app activity launches. This is an anonymous request without a GitHub login, not a media upload. GitHub receives ordinary network request information, such as your IP address and the update-check user agent. An APK download opens in your browser only when you choose it; the app does not silently install an update.
  • Receiving runs while the app's activity is visible; an outgoing cast can continue in a foreground service. Use Stop to end sending. Android's system controls also govern screen and microphone access.

Analytics, storage and your choices

The apps do not include an advertising or analytics service or upload casting diagnostics to RedRain automatically. Local settings and diagnostic state stay on your device unless you choose to share them. System diagnostics are also subject to your operating system's policies.

Stop sharing when finished and close the receiver when you do not want incoming casts. Review screen/audio consent and Android app permissions. Android's Clear storage or uninstall controls remove app-private data; uninstalling the Windows app may leave local settings that you can remove through your user profile. This does not delete information already shared with another device, GitHub or a public support ticket.

This website, downloads and public support

This static website has no analytics, advertising, cookies, external fonts or contact forms added by RedRain. It is hosted by GitHub Pages. GitHub may process visitor request information, including IP addresses, for hosting, security and operation. GitHub also handles Android release checks, downloads and issue submissions under the GitHub General Privacy Statement. Microsoft Store visits and installations are governed separately by Microsoft's Privacy Statement.

Privacy questions can be raised through RedrainCast's public support issues. Issues and attachments are public. Do not post private media, personal information, network addresses or unredacted logs. No confidential contact channel is currently listed; do not submit confidential material through public issues.
