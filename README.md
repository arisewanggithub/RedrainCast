# RedrainCast product website

Public homepage, privacy policy and support for RedrainCast by RedRain.
This repository contains the static product website, not application source.

- Homepage: https://arisewanggithub.github.io/RedrainCast/
- Privacy: https://arisewanggithub.github.io/RedrainCast/privacy/
- Support: https://arisewanggithub.github.io/RedrainCast/support/

GitHub Pages serves the root of `main`. Relative page and asset links work
under the project path and on a future custom domain. No custom domain is
configured. The site uses plain HTML/CSS and an SVG brand mark, without a build
step, external fonts, analytics or a JavaScript framework.

Windows distribution is Microsoft Store only (coming soon). The separate
public RedrainCast-Releases repository hosts Android APKs and release materials.
Support issues here are public: do not submit private media or unredacted logs.
