# RedrainCast product website

Public homepage, privacy policy and support for RedrainCast by RedRain.
This repository contains the static product website, not application source.

- Homepage: https://redraincast.redrain.ccwu.cc/
- Privacy: https://redraincast.redrain.ccwu.cc/privacy/
- Support: https://redraincast.redrain.ccwu.cc/support/

GitHub Pages serves the root of `main` at `https://redraincast.redrain.ccwu.cc/`.
Relative page and asset links work under the project path and on the custom
domain configured in `CNAME`. The site uses plain HTML/CSS and an SVG brand mark, without a build
step, external fonts, analytics or a JavaScript framework.

RedrainCast for Windows is available exclusively through Microsoft Store. The separate
public [RedrainCast-Android repository](https://github.com/arisewanggithub/RedrainCast-Android/releases)
hosts new Android APKs and release materials alongside its source.
Support issues here are public: do not submit private media or unredacted logs.
